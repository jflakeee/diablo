# 디아블로 2 호라드릭 큐브 레시피 리서치

작성일: 2026-10-08
출처: https://luckysevens.tistory.com/613 ("디아블로2 레저렉션 아이템 획득 가이드")
목적: `prototype/game_dungeon/craft.gd`의 큐브 레시피를 D2(레저렉션) 원작 레시피와
대조하기 위한 참고 자료. [d2-item-system-reference.md](d2-item-system-reference.md)의 후속 리서치 — 이 문서는
"변환/생성" 레시피 쪽에 집중. 설계 확정이 아니라 **원작 레시피 정리**이며, 적용
여부는 별도 브레인스토밍에서 결정한다.

## 1. 제작(Crafted) 아이템 레시피 — 보석류

출처 글은 "Hit Power/Blood/Caster/Safety" 네 계열 중 **캐스터(Caster) 계열**
레시피를 구체 아이템 조합으로 제시한다(매직 베이스 + 룬 + 최상급 보석 + 주얼):

| 완성 아이템 | 베이스 + 재료 | 부여 옵션 |
|---|---|---|
| 목걸이 | 매직 목걸이 + **랄(Ral)룬** + 최상급 자수정(Amethyst) + 매직 주얼 | 시전속도 + 마나재생 + 마나 |
| 벨트 | 매직 라이트벨트/샤크스킨벨트/뱀파이어팽벨트 + **아이드(Ith)룬** + 최상급 자수정 + 주얼 | 시전속도 + 마나재생 + 마나 |
| 장갑 | 매직 헤비글러브/샤크스킨글러브/뱀파이어본글러브 + **네프(Nef)룬** + 최상급 루비(Ruby) + 주얼 | 라이프 흡수 + 라이프 + 강한 타격(Crushing Blow) |
| 반지 | 매직 반지 + **솔(Sol)룬** + 최상급 루비 + 주얼 | 라이프 흡수 + 라이프 + 힘 |

패턴 공통점: **베이스는 반드시 매직 아이템**, 재료는 룬 1개 + 최상급(Perfect) 보석
1개 + 주얼 1개의 3종 조합. [d2-item-system-reference.md](d2-item-system-reference.md) 3절("제작 아이템은 매직
베이스 필수, 고정 속성 3~4개 + 랜덤 접사")과 정합 — 이 레시피들이 바로 그 "고정
속성" 부여 수단으로 보인다.

## 2. 무작위 소켓 생성(아이템 종류별 다른 룬 조합)

| 베이스 종류 | 재료 |
|---|---|
| 갑옷(Armor) | **탈(Tal)룬 + 주울(Zul)룬** + 최상급 토파즈(Topaz) + 노말 갑옷 |
| 무기(Weapon) | **랄(Ral)룬 + 앰(Amn)룬** + 최상급 자수정 + 노말 무기 |
| 헬멧(Helm) | **랄(Ral)룬 + 주울(Zul)룬** + 최상급 사파이어(Sapphire) + 노말 헬멧 |
| 방패(Shield) | **탈(Tal)룬 + 앰(Amn)룬** + 최상급 루비 + 노말 방패 |

**현재 프로젝트와의 차이**: `craft.gd`의 `SOCKET_CATALYST`는 **해골(skull) 3개
단일 재료**로 아무 장비에나 소켓 2개를 고정 부여하는데, 원작은 **장비 종류별로
서로 다른 두 룬 + 최상급 보석 1종**을 요구하고(갑옷=토파즈, 무기=자수정,
헬멧=사파이어, 방패=루비), **"노말" 등급 베이스만** 대상이 되는 것으로 보인다
(매직/레어 등 이미 다른 품질이 된 아이템은 이 레시피 대상이 아닐 가능성 — 원문
미확인, 후속 조사 필요). 소켓 "개수"가 몇 개 나오는지는 이 글에 명시되지 않음
(레시피마다 2개 고정일 수도, ilvl 기반 랜덤일 수도 있음 — [d2-item-system-reference.md](d2-item-system-reference.md)
7절의 "품질별 소켓 상한"과 별개로 **큐브 레시피 자체의 소켓 개수 규칙**은 추가
조사 필요).

## 3. 아이템 관리 레시피

- **소켓 내용물 제거**: 아이템 + **헬(Hel)룬** + 마을 차원문의 두루마리(Scroll
  of Town Portal). (소켓 자체가 사라지는 게 아니라 끼워진 보석/룬/주얼만 제거되는
  것으로 추정 — 원문에 명확한 구분 없음.)
- **무기 수리/충전**: 무기 + **오르트(Ort)룬** + 최하급(Chipped) 보석.
- **방어구 수리/충전**: 방어구 + **랄(Ral)룬** + 하급(Flawed) 보석.

**참고**: "충전"은 스태프/완드 등 충전식 아이템의 충전량 회복을 의미하는 것으로
보임(원문에 구분 서술 없음).

## 4. 레어/매직 아이템 옵션 재굴림(리롤)

- **레어 아이템 재굴림**: **최상급 해골(Perfect Skull) 6개** + 레어 아이템.
- **매직 아이템 재굴림**: **최상급 해골 3개** + 매직 아이템.

**현재 프로젝트와의 차이**: `craft.gd`의 `REROLL_CATALYST`는 **토파즈(topaz) 3개**이고
레어/매직 구분 없이 동일 비용(`REROLL_COST=3`)으로 처리한다. 원작은 (a) 재료가
**최상급 해골**이고(토파즈 아님), (b) **레어는 6개, 매직은 3개**로 품질별 비용이
다르다. 이 프로젝트는 현재 "해골"을 **소켓 부여 재료**로 쓰고 있어(세션 로그 기준
`SOCKET_CATALYST = "skull"`), 원작의 "해골=재굴림 재료" 용도와 **정반대로 배정**된
상태 — 재료 매핑을 원작에 맞게 바꿀지는 별도 판단 필요(이미 라이브된 게임 밸런스를
건드리는 변경이라 신중 요망).

## 5. 아이템 등급 업그레이드(노말→익셉셔널→엘리트)

**무기**:

| 전환 | 재료 |
|---|---|
| 노말 유니크 → 익셉셔널 | 최상급 에메랄드(Emerald) + **랄(Ral)룬 + 솔(Sol)룬** |
| 익셉셔널 유니크 → 엘리트 | 최상급 에메랄드 + **룸(Lum)룬 + 풀(Pul)룬** |
| 노말 레어 → 익셉셔널 | 최상급 사파이어 + **오르트(Ort)룬 + 앰(Amn)룬** |
| 익셉셔널 레어 → 엘리트 | 최상급 사파이어 + **팔(Fal)룬 + 우움(Um)룬** |

**방어구**:

| 전환 | 재료 |
|---|---|
| 노말 유니크 → 익셉셔널 | 최상급 다이아몬드(Diamond) + **탈(Tal)룬 + 샤에(Shael)룬** |
| 익셉셔널 유니크 → 엘리트 | 최상급 다이아몬드 + **코(Ko)룬 + 렘(Lem)룬** |
| 노말 레어 → 익셉셔널 | 최상급 자수정 + **랄(Ral)룬 + 주울(Zul)룬** |
| 익셉셔널 레어 → 엘리트 | 최상급 자수정 + **코(Ko)룬 + 풀(Pul)룬** |

이 전환은 **베이스 아이템 자체의 등급(노말/익셉셔널/엘리트 무기·방어구 타입)**을
바꾸는 것으로, 유니크/레어의 "품질"(퀄리티 타입)을 바꾸는 게 아니라 **베이스
템플릿을 상위 티어로 교체**하는 레시피다(예: 숏소드 유니크 → 그 유니크의
익셉셔널급 베이스인 브로드소드 버전으로). 이 프로젝트의 베이스 아이템 체계에
"노말/익셉셔널/엘리트" 3단계 구분이 있는지부터 확인 필요 — 세션 기록상
`WEAPON_BASES`/`ARMOR_BASES` 배열이 단일 목록으로 보여(등급 구분 없음) 이
레시피 자체는 **현재 베이스 체계로는 적용 불가**, 베이스 아이템 체계 확장이
선행돼야 하는 큰 작업으로 분류.

## 6. 참고용 추천 아이템 시세 정보(비규칙, 참고만)

- 매직 모너크 방패 "지존급" 옵션 조합 예시: `30% 매우 빠른 방어속도 증가 + 20%
  공격저지 성공율 증가 + 4 소켓`.
- 레어 주얼의 고가치 옵션 조합 예: `7% 회복 속도 + 9 힘 + 9 민첩`.

(이 절은 생성 규칙이 아니라 레저렉션 커뮤니티의 "이런 옵션이 비싸다"는 시세
정보 — 게임 밸런스 참고용으로만 남겨둠.)
