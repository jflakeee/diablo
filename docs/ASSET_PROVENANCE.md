# Asset provenance

The canonical game runtime uses project-generated assets only.

- Static and animation textures are generated by `game_dungeon/art/pixel_gen.gd`.
- Runtime sound effects are synthesized by `game_dungeon/sfx_gen.gd`.
- HUD shapes, icons, and controls are drawn by project code or generated recipes.
- Godot's built-in fallback font is used; no third-party font file is bundled.
- No extracted game image, audio, font, source file, screenshot trace, or modified proprietary asset is an allowed input.

Every compiled atlas manifest records:

- `format_version` and `generator_version`
- hashes for recipes, monster data, palettes, and archetypes
- project-generated origin and project-original license declaration
- the recipe ID and recipe type for every static asset or animated actor
- the output atlas MD5

The compiler `verify` command rejects missing provenance, unresolved recipes, mismatched hashes, nondeterministic output, and partial publication.
