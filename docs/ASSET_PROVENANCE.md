# Asset provenance

The canonical world, actor, effect, audio, and identity assets are project-generated.
During the visual-redesign migration, a small set of CC0 UI template textures is
temporarily bundled behind a replaceable theme adapter.

- Static and animation textures are generated by `game_dungeon/art/pixel_gen.gd`.
- Runtime sound effects are synthesized by `game_dungeon/sfx_gen.gd`.
- HUD shapes, icons, and controls are drawn by project code or generated recipes.
- The Ashen Depths application icon was generated specifically for this project with OpenAI's built-in image generation tool on 2026-09-23 from an original fractured-obsidian-gate prompt. `assets/app_icon_source.png` is the canonical source; `tools/icon_builder.gd` deterministically produces the 144, 180, and 512 pixel delivery variants. The source is excluded from release packs to avoid runtime duplication.
- Godot's built-in fallback font is used; no third-party font file is bundled.
- No extracted game image, audio, font, source file, screenshot trace, or modified proprietary asset is an allowed input.

## Temporary CC0 UI templates

- `assets/ui/template/button_*.png` and `panel_brown.png` come from Kenney's
  **UI Pack: RPG Expansion**, licensed CC0 1.0.
- `assets/ui/template/panel_border_double.png` comes from Kenney's
  **Fantasy UI Borders**, licensed CC0 1.0.
- Original archives, exact download URLs, SHA-256 values, and license texts are
  stored in `game_dungeon/third_party_sources/` and excluded from Godot imports
  by `.gdignore`.
- Runtime code references only semantic names exposed by
  `game_dungeon/ui/template_theme.gd`. Local generator output will replace these
  textures without changing gameplay UI code.

Every compiled atlas manifest records:

- `format_version` and `generator_version`
- hashes for recipes, monster data, palettes, and archetypes
- project-generated origin and project-original license declaration
- the recipe ID and recipe type for every static asset or animated actor
- the output atlas MD5

The compiler `verify` command rejects missing provenance, unresolved recipes, mismatched hashes, nondeterministic output, and partial publication.
