# 소켓 시스템 게임플레이 활성화

작성일: 2026-10-04
대상: `prototype/game_dungeon`
상태: 구현 기준 확정

## 1. 목표

소켓/보석/룬/룬워드(`craft.gd`, `item.gd effective_affixes`)는 완전히 구현·단위테스트까지
되어 있었지만, 실제 게임플레이에서 `make_socketed()`/`socket_insert()`를 호출하는 경로가
`_craft_selftest()` 말고는 전혀 없었다 — 드롭도, 도박도, 큐브도 소켓 있는 아이템을 만들지
않아 이 시스템 전체가 실전에서 닿을 수 없는 죽은 코드였다. 큐브에 "소켓 부여" + "소켓에
삽입" 두 레시피를 추가해 처음으로 실제로 쓸 수 있게 만든다.

## 2. 완료 조건

1. 스컬(신규로 드롭 테이블에 추가) 3개 + 소켓 없는 일반(normal) 품질 무기/방어구 1개 →
   그 자리에서 소켓 2개를 부여한다(새 아이템을 만들지 않고 가방의 기존 아이템을 그대로
   변형).
2. 소켓이 열려 있는 아이템마다, 보유한 보석/시길 재료 종류별로 "삽입" 버튼이 뜨고 눌러서
   `Item.socket_insert()`를 호출한다. 재료는 1개 소비된다.
3. 두 룬(Vey+Ahn)을 순서대로 삽입하면 기존 룬워드 매칭(`Tempered Edge`)이 그대로
   작동한다 — 룬워드 로직 자체는 변경하지 않는다.
4. 큐브 UI에서 두 섹션 모두 재료/대상 유무에 따라 버튼이 뜨고/비활성화된다.

## 3. 범위와 비범위

### 범위
- `craft.gd`: `SOCKET_CATALYST`("skull")/`SOCKET_COST`(3)/`SOCKET_COUNT`(2),
  `can_add_sockets()`/`add_sockets()`(제자리 변형, `make_socketed()` 재사용 안 함 — 그건
  새 아이템을 만들어서 가방 아이템에 못 씀)
- `main.gd`: 스컬을 몬스터 드롭 재료 풀에 추가, `_rebuild_cube()`에 "ADD SOCKETS"/
  "INSERT INTO SOCKET" 두 섹션, `_add_sockets_to_item()`/`_insert_material_into_item()`,
  `_craft_selftest()` 6번째 체크
- `tools/cube_ui_test.gd`: 두 버튼의 탐지/클릭/재료소비 검증

### 비범위
- 소켓 개수 가변화(항상 2개 고정 — 현재 룬워드 2개가 전부 2소켓 레시피라 2로 충분)
- 보석 품질(chipped~perfect)별 소켓 효과 차등화(`GEM_STATS`가 품질 무관 고정값인 기존
  한계 — 이번 작업은 "소켓을 쓸 수 있게" 하는 것이고 "품질별 효과"는 별도 확장)
- Gloom Crown 룬워드(helm) 활성화 — 이 프로젝트에 헬름 슬롯이 없어 애초에 도달 불가능.
  굳이 손대지 않고 비활성 상태로 남긴다.
- 소켓 제거/재조정 레시피

## 4. 상세 설계

### 4.1 왜 스컬인가

토파즈와 같은 이유: `GEM_STATS`의 skull 항목은 `armor: {life: 0}`로 소켓 효과가 0이라
원래 쓸모가 없었다. 드롭 테이블에도 없었으므로(`main.gd` 몬스터 드롭 `gems` 배열) 이번에
함께 추가했다 — 재료 종류를 늘리지 않고 기존에 버려지던 재료에 새 용도를 준다.

### 4.2 제자리 변형이 필요한 이유

`Item.make_socketed(base, sockets)`는 `generate(null, base, 1, "normal")`로 **새
아이템을 생성**해 소켓 필드를 붙인다 — 가방에 이미 있는 아이템 인스턴스에는 쓸 수 없다
(다른 아이템이 되어버림). 그래서 `Craft.add_sockets()`는 재료 검사 후 대상 딕셔너리에
직접 `it["sockets"] = 2; it["socketed"] = []`를 대입한다. 조건은 "일반 품질 + 무기/방어구
+ 소켓 없음"으로 제한(매직/레어/세트/유니크에 소켓을 더하는 것은 D2에서도 특수 레시피
영역이라 이번 범위에서 제외).

### 4.3 삽입 UI

큐브 패널에서 소켓이 열려 있는 아이템마다 보유 재료 전부에 대해 "Insert <재료명>" 버튼을
평평하게(직계 자식으로, HBoxContainer로 묶지 않음 — 리롤 작업 때 겪은 중첩 자식 탐지
실패를 반복하지 않음) 나열한다. 룬 재료(`rune_` 접두사)와 보석 재료(품질 접미사 `:quality`
제거 후 베이스 이름)를 `Item.socket_insert()`가 기대하는 `{kind, id}` 형태로 변환한다.

### 4.4 검증

- `_craft_selftest()` 6번째 체크(`[P4] socket: ...`): 스컬 소비 → 소켓 2개 부여 → Vey+Ahn
  삽입 → 룬워드 매칭(`Tempered Edge`, ed=20)까지 한 번에 확인. 최종 `ok`에는 이미
  `_craft_selftest_ok`로 편입되어 있어 추가 배선 불필요(지난 리롤 작업 때 이미 고침).
- `tools/cube_ui_test.gd`: "Add 2 Sockets"/"Insert ..." 버튼 탐지·클릭·재료소비 검증,
  `[CUBE_UI] ... socket=true verdict=`.
- barb/sorc 표준 오토퀴트로 드롭 테이블에 스컬이 추가된 것이 기존 동작을 깨지 않는지
  확인(재료 종류 하나 추가는 수량 제한 없는 재료함 구조상 안전하지만, 그래도 재실행해
  확인).
