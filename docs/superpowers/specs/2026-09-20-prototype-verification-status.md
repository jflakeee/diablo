- 작성일: 2026-09-20
- 검증 머신: **Intel i5-3360M(2C/4T) · 8GB · Intel HD 4000 · Win10** (최저사양 타깃)
- 엔진: **Godot 4.7.2** · Compatibility(OpenGL3 → 자동 ANGLE → Direct3D11)

## 2. 딥리서치 공식 → 코드 반영 검증

리서치 문서의 공식이 실제 코드에서 작동함을 실측으로 확인:

| 공식(출처) | 코드 | 실측 증거 |
|-----------|------|-----------|
| 명중률 200·AR/(AR+DR)·Alvl/(Alvl+Dlvl) (P1§1) | `combat.chance_to_hit` | 27공격 26적중 등 |
| 바바리안 Life 55+4·Vit+2·Lv (P1§2) | `barbarian_max_life` | life=157 |
| 소서리스 Life/Mana (P1§2) | 인라인 | life=81 mana=107 |
| 물리 데미지 min~max×(1+ED) (P5§1) | `physical_damage` | 데미지 텍스트 |
| 데들리스트라이크 2배 (P5§4) | `roll_deadly_strike` | CRIT 표시 |
| 접사 규칙 50/25/25 (P1§3) | `item.generate` | 매직/레어 롤 |
| MF 수확체감 MF×600/(MF+600) (P5§5) | `item.roll_drop` | 드롭 품질 |
| 룬워드 순서 판정 (P2§4) | `craft.match_runeword` | Steel=Tir+El, 역순 불가 |
| Perfect 보석 슬롯 스탯 (P6§2) | `craft.gem_stat` | Ruby→+38life |
| 큐브 룬업 (P3§3) | `craft.upgrade_rune` | El×3→Eld |
| 보스 3패턴 (P3§4) | `_boss_ai` | melee/nova/spray |
| 25 FPS 프레임모델 (P2§1) | `physics_ticks=25` | rate 25.14/s |

→ **리서치는 장식이 아니라 코드의 1차 근거로 작동**함이 실증됨.

## 3. 정식화 백로그 (심화 대상, 우선순위)

프로토타입은 "시스템이 공식대로 동작함"을 증명했다. 정식 게임화에 남은 것:

### A. 데이터 임포트 (최우선 — 콘텐츠의 뼈대)
- `monstats.txt` → 몬스터 전수 스탯/저항/AI, 난이도 스케일링(P2§3)
- `weapons.txt`/`armor.txt` → 베이스 전수(qlvl·소켓상한·요구스탯)
- `MagicPrefix/Suffix.txt` → 접사 전체 테이블·그룹·spawnWeight
- `uniqueitems.txt`/`setitems.txt`·`runes.txt`·`gems.txt`·`cubemain.txt`
- `skills.txt` → 7클래스 210스킬 계수·마나·시너지

### B. 전투 심화 (Part 5·6 완전 적용)
- 저항/면역 전투 반영, 블록 판정, IAS/FCR/FHR 브레이크포인트 애니메이션
- 무기 기반 데미지/WSM, 흡혈·크러싱블로우·오픈운즈, 독 DoT

### C. 콘텐츠
- 랜덤 던전 생성(프리셋 청크 + 패턴매칭, P1 심화), 액트1~5 구역·워프·퀘스트
- 나머지 5클래스 스킬트리, 유니크/세트/룬워드 전체

### D. UI/UX·메타
- 인벤토리 그리드(드래그&드롭), 스킬트리 화면, 스탯 배분, 창고
- P10 세이브(직렬화)·오디오, 오리지널 자산 파이프라인

### E. 온라인 정식화
- 계정 DB·인증, 캐릭터 서버 영속화, 상태 동기화 최적화, 거래 UI·시세, 안티치트

### F. 통합
- 현재 프로토타입 8개(단계별 복제본)를 **단일 정식 프로젝트로 병합**, 공용 모듈화
