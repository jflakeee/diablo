# 용병 종류 다양화 설계

작성일: 2026-10-02
대상: `prototype/game_dungeon`
상태: 구현 기준 확정

## 1. 목표

지금까지 용병은 "Ember Scout"(원거리 화염 화살) 1종으로 고정되어 있었다. 플레이어가 상인
패널에서 용병 종류를 순환 전환할 수 있게 해, 전투 스타일(원거리/근접, 원소)에 선택지를 준다.

## 2. 완료 조건

1. 용병 종류는 3종: Ember Scout(원거리/화염, 기존 스탯 그대로), Iron Guard(근접/무속성,
   생명력·방어력 높고 사거리 1.5), Frost Acolyte(원거리/냉기, 생명력 낮지만 적중 시 슬로우).
2. 상인 패널 버튼("Mercenary: <종류> (Cycle)")으로 다음 종류로 순환 전환. 레벨/장비/킬 수/
   부활 타이머는 그대로 유지, 스탯만 재계산.
3. 저장/불러오기 시 선택한 종류가 유지된다(스키마 v16, 기본값 "scout").
4. HUD/로그에 현재 용병 종류가 노출된다.

## 3. 범위와 비범위

### 범위
- `mercenary.gd`: `TYPES`/`TYPE_ORDER` 테이블, `normalize_type`/`next_type`, `stats()`에
  `merc_type` 인자 추가, `selftest()`
- `main.gd`: `_merc_type` 상태, `_spawn_merc`/`_cycle_merc_type`/`_merc_ai`/`_merc_fire`/
  `_merc_melee`, 저장/불러오기, 상인 패널 버튼, HUD/로그 문구
- `save_store.gd`: 스키마 v15→v16 마이그레이션(`merc_type` 기본값 "scout")

### 비범위
- 용병 전용 스킬 트리나 장비 슬롯 확장(기존 weapon/armor 슬롯은 종류 무관 그대로 사용)
- 상인에서 용병을 "고용"하는 금전 비용(이미 소유한 용병의 스타일만 바꾸는 것으로 범위 제한)
- 새 전용 아트(기존 제너릭 휴머노이드 실루엣 + 색상 차별화로 충분, `pixel_gen.gd`의
  warden/arcanist 전용 분기 같은 신규 실루엣은 범위 밖)

## 4. 상세 설계

### 4.1 스탯 템플릿 (`mercenary.gd`)

`TYPES` 딕셔너리에 종류별 기본 스탯(레벨당 성장 포함), 사거리, 공격 쿨다운, 근접 여부, 원소를
저장한다. `stats()`는 기존 레벨 스케일링 공식은 그대로 두고 기준값만 종류별로 교체한다. 장비
보너스/인핸스드 데미지/저항 합산 로직은 전부 공유(종류 무관).

### 4.2 전투 (`main.gd`)

`_merc_ai`는 종류 템플릿에서 사거리/쿨다운을 읽어 기존 분기 구조를 그대로 쓴다. 근접
(`melee=true`)이면 `_merc_melee`(물리 피해만, LOS 체크 없음 — 사거리 자체가 인접이라 불필요),
아니면 `_merc_fire`(원소 부가 피해: fire는 기존 로직 그대로, cold는 소량 부가 피해 +
`slow_timer = 1.4`로 플레이어 냉기 무기와 동일한 슬로우 규칙 재사용).

### 4.3 전환 (`_cycle_merc_type`)

상인 패널 버튼 1개로 `TYPE_ORDER`를 순환한다. 전환 시 이름/아트/스탯만 다시 적용하고 레벨·
장비·킬 수·부활 타이머는 그대로 둔다. 생명력이 새 최대치를 넘으면 클램프, 그 외에는 비율
회복 없이 현재 값 유지(완전 회복은 아님 — 타운에서 자유롭게 바꿀 수 있어 악용 방지 불필요
수준이라 단순하게 둠).

### 4.4 검증

- `Mercenary.selftest()`: 기본값 폴백, 순환 순서, 가드가 스카웃보다 생명력/방어력이 높고
  사거리가 짧은지, 세 종류의 근접/원소 플래그가 설계대로인지, 아콜라이트가 스카웃보다
  생명력이 낮은지 확인. `main.gd` 오토퀴트에서 `[MERC_TYPE] selftest verdict=` 출력 +
  최종 `ok` 집계에 포함.
- `save_store.selftest()`: v15→v16 마이그레이션이 `merc_type` 기본값 "scout"을 채우는지
  확인(checks 22→23).
- 오토퀴트(barb/sorc): `[MERC] kills=... state=... type=scout` 로그로 기본 종류가 정상
  동작하는지 확인(전환 자체는 상인 패널 UI 경로라 오토퀴트 플레이 경로에는 묶지 않음 —
  인벤토리 그리드 UI 때와 동일한 판단).
