# 설계 대비 결과물 비교 분석

- 작성일: 2026-09-21
- 대상: 아이디어 문서 → 마스터 로드맵(P0~P13) → 딥리서치 8부 → 프로토타입 13종 → 웹 배포
- 관련: [로드맵](./2026-09-19-diablo2-clone-master-roadmap-design.md) · [검증 상태 종합](./2026-09-20-prototype-verification-status.md) · [PROGRESS](../../../prototype/PROGRESS.md)

> **핵심 결론:** 초기 합의 범위(옵션 3 = "코딩 없이 로드맵+딥리서치 문서만")를 **대폭 초과**하여, 로드맵 전 시스템(P0~P13)을 **프로토타입+저사양 실기 검증**하고 **웹에 배포**까지 완료했다. 단, 모든 결과물은 **메커니즘 실증(프로토타입) 수준**이며, **정식 콘텐츠 볼륨·오리지널 자산·정확 수치**는 미완(설계상 후속 단계).

## 1. 아이디어 문서 요구사항 대비

### "동일하게 구현할 요소" (D2와 동일)
| 요구 | 결과 | 수준 |
|------|------|------|
| 아이템 드롭 확률 | ✅ NoDrop·품질 롤·MF 수확체감 공식 구현 | 공식 O / TC 전수 X |
| 아이템 분류 | ✅ normal/magic/rare + prefix/suffix 접사 | 규칙 O / 접사 부분집합 |
| 스테이지(구조) | ✅ 랜덤 던전 생성(프리셋 룸+스패닝트리) | 개념 O / D2 원본 타일셋 X |
| 인스턴트 맵 | ✅ 시드 기반 매번 다른 완전연결 던전 | O |
| 액션 애니메이션 | ❌ 색 사각형/다이아 플레이스홀더 | **미구현**(스프라이트 애니 없음) |
| 보석 | ✅ Perfect 보석 슬롯별 스탯 | 부분집합 |
| 룬워드 | ✅ 순서 판정(Steel/Stealth/Nadir) | 3종(원본 ~80) |
| 큐빙 | ✅ 룬/보석 업그레이드·소켓팅 | 부분집합 |
| 스킬트리 | ⚠️ 바바리안4·소서리스3 스킬 동작 | 스킬 O / **트리 UI·시너지 전수 X** |
| 몬스터 AI | ✅ 근접/원거리/보스 분기 + A* 추격 | 3유형 |
| 보스 공격 루틴 | ✅ 안다리엘 3패턴 상태머신 | 보스 1종 |

### "다르게 구현할 요소" (모바일 적응)
| 요구 | 결과 | 수준 |
|------|------|------|
| UI | ✅ 가상 조이스틱·스킬버튼·인벤 그리드(드래그&드롭)·캐릭터 화면·클래스 선택·확대 | **양호** |
| 거래 시스템 | ✅ 서버 권위 에스크로 거래(P13) | 기초 데모 |
| 스테이지 레벨 | ✅ 랜덤 생성 | O |
| 스토리 | ❌ 없음 | 미구현 |
| 사운드 | ❌ 없음 | 미구현 |
| 디자인·스프라이트·캐릭터 | ❌ 플레이스홀더 도형 | **미구현**(오리지널 자산 제작 안 함) |

## 5. 정량 요약

- **문서:** 로드맵 + 딥리서치 8부 + 검증/분석 = 11
- **프로토타입:** 13 (P0~Phase7·통합·데이터구동·랜덤던전·캡스톤·UI·전투심화·세이브)
- **커밋:** 30+
- **실기 검증:** 전 프로토타입 HD4000 PASS
- **배포:** 2개 웹 빌드 라이브(던전크롤·통합본)

### 달성률(설계 시스템 기준, 프로토타입 실증 기준)
- **시스템 커버리지: 13/13 (100%)** — 모든 설계 시스템이 동작
- **"완성도(정식화)" 기준: 약 30~40%** — 메커니즘은 되나 콘텐츠 볼륨·자산·정확 수치 미완

## 6. 미달성 / 정식화 잔여 (정직한 갭)

**가장 큰 갭 = 콘텐츠·자산 볼륨** (설계상 "다르게 구현"과 후속 데이터 임포트):
1. **오리지널 자산 전무** — 스프라이트/애니메이션/사운드/디자인 미제작(플레이스홀더 도형). 아이디어 문서의 "다르게 구현(스프라이트·사운드·디자인·캐릭터)" 핵심 미수행.
2. **콘텐츠 볼륨** — 몬스터 6·아이템 베이스 6·접사 12·룬워드 3·클래스 2·보스 1·액트 부분. 원본은 각각 수백 규모.
3. **정확 수치 미임포트** — `monstats/weapons/skills.txt` 등 원본 데이터 대신 근사값.
4. **브레이크포인트·난이도 스케일링** — 연구했으나 미적용.
5. **스킬트리 UI/시너지 전수, 스토리/퀘스트, 온라인 영속화** — 미완.

**완화책(이미 마련됨):** 데이터 구동 파이프라인(JSON 로더)으로 콘텐츠는 "코드 변경 없이 데이터 추가"만 하면 확장 가능. 원본 txt→JSON 임포트가 정식화의 다음 관문.

## 7. 종합 평가

- **설계 충실도:** 로드맵의 시스템 분해가 실제 구현 순서와 정확히 일치했고, 딥리서치 공식이 코드의 1차 근거로 작동 → **설계→구현 추적성 우수**.
- **초과 달성:** 문서만 만들기로 한 범위에서 **저사양 실기에서 도는 배포된 플레이 가능 게임**까지 도달.
- **정직한 한계:** "디자인 제외 모든 요소 D2와 동일"이라는 원 목표 기준으로는 **콘텐츠·자산·정확도가 프로토타입 수준**. 즉 "**모든 시스템이 증명된 수직 슬라이스**"이지 "완성된 D2 클론"은 아니다.
- **다음 관문:** ① 오리지널 자산 파이프라인 ② 원본 데이터 txt→JSON 대량 임포트 ③ 브레이크포인트·난이도 ④ 스킬트리/액트 콘텐츠 확장.
